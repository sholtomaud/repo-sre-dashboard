# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/sholtomaud/repo-sre-dashboard/security/advisories/new).

We aim to reply within 2 working days and to fix confirmed issues within 7
days, the dashboard's own limit for security issues.

## Scope

The Action runs in other people's workflows with their token, so reports
about how it handles that token, what it writes to the Pages site, or
anything that could run untrusted code are especially welcome.

## Supported versions

Only the latest release (the `v1` tag) receives security fixes.
