# Repo SRE Dashboard

A GitHub Action that publishes a reliability dashboard for any repository to GitHub Pages: who resolves its issues (AI agents or humans), how fast, whether the backlog is growing, how issues are closed, delivery (DORA) metrics and response times, with a forecast.

Work in progress. It grows out of the [Developer Doomsday Clock](https://github.com/sholtomaud/aws-emulator-bug-tracker) built for `aws/aws-emulator`.
